# frontend/ — React + Vite web UI

The web tier's user interface. **Presentation only** — it drives the engine through the `hosts/web`
adapter (`executeCli(args)`); it holds **no business logic** (that's `engine/`).

For the bootstrap: a scaffolding UI (run `dlc new`, browse the OPFS result, show console output, download
the project).

See [plan](../docs/DEVALBO-ILC-GO-PLAN.md) §5.1, §16.2.
